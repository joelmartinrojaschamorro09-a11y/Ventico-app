VENTICO APP - página web (RC Estudio Digital)

Qué hay aquí
  index.html   -> página de presentación y descarga (la portada del sitio)
  img/         -> capturas de la app e íconos
  web/         -> Ventico App web (la que se usa desde el navegador)
  descargas/   -> aquí va el APK, con el nombre exacto VenticoApp.apk
  sw.js        -> retira la versión anterior de la app que estaba en la raíz

Cómo subirlo al repositorio (el mismo de GitHub Pages)
  1. Sube TODO el contenido de esta carpeta a la raíz del repositorio
     (Add file > Upload files, arrastrando las carpetas img, web y descargas
     y los archivos index.html y sw.js). Acepta reemplazar index.html y sw.js.
  2. Cuando GitHub Actions termine el APK: descárgalo, descomprímelo,
     cámbiale el nombre a VenticoApp.apk y súbelo dentro de la carpeta descargas/.
  3. Espera 1 o 2 minutos a que termine "pages build and deployment".

Direcciones
  Página:  https://TU-USUARIO.github.io/NOMBRE-DEL-REPOSITORIO/
  App web: https://TU-USUARIO.github.io/NOMBRE-DEL-REPOSITORIO/web/

Los archivos manifest.webmanifest e íconos que estaban antes en la raíz ya no se usan;
puedes dejarlos o borrarlos. No borres los archivos del proyecto Android (carpetas app y gradle, gradlew, *.gradle.kts).
